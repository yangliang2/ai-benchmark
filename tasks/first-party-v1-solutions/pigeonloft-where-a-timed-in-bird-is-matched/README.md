# The pigeon loft

A club of half a dozen lofts, a race every Saturday through the summer, and
a great deal of paper.

- `rings.py` — ring numbers, and when two writings of one are the same bird.
- `entries.py` — the sheets: what each loft entered, for which race, and the
  hours a race is open between.
- `clocking.py` — the clocking: the birds timed in, and which line of the
  sheets each of them counts for.

The first two answer one narrow question each and try nothing on anything;
the third is where a bird timed in meets the paper.

Run the tests with `pytest`. Nothing outside the standard library is needed.
